# Linux & CI/CD Notes

## Linux Basics
- Navigation: `ls`, `cd`, `pwd`
- File management: `cp`, `mv`, `rm`, `mkdir`
- Permissions: `chmod`, `chown`

## Git & GitHub
- Clone repo: `git clone <url>`
- Branching: `git checkout -b branch-name`
- Commit & Push: `git add .`, `git commit -m "message"`, `git push`

## CI/CD Concepts
- CI (Continuous Integration): automatically build and test code
- CD (Continuous Deployment): automatically deploy code to production
- Common Tools: GitHub Actions, Jenkins, Travis CI
