
# DevOps Learning Journey

This repository documents my learning journey as I transition from web development into DevOps engineering.

## Background

I have a background in web development, where I gained experience building user-facing applications. Through this process, I became increasingly curious about what happens after development—how applications are deployed, scaled, monitored, and maintained in real-world production environments. This curiosity led me to explore DevOps engineering and its role in bridging development and operations.

## Current Learning Focus

I am currently learning foundational DevOps concepts, including:
- DevOps culture and collaboration
- Continuous Integration and Continuous Deployment (CI/CD)
- Automation in software delivery
- Basics of cloud infrastructure
- System reliability and scalability concepts

## Tools I Plan to Learn and Use

As I progress, I plan to gain hands-on experience with the following tools and technologies:
- Git and GitHub
- Linux fundamentals
- Docker
- CI/CD tools (such as GitHub Actions)
- Cloud platforms (AWS or similar)
- Infrastructure as Code concepts

## Goals

The goal of this repository is to track my growth, document my learning, and showcase practical exercises and projects as I continue developing my skills through structured training, mentorship, and hands-on practice.

This repository will be updated regularly as I progress in my DevOps engineering journey.
